# volumosos

Agendamento de coleta de resíduos volumosos por região, com checklist para o motorista
(PWA sem build e sem login). Publicado em https://ecopontos.github.io/volumosos/.

**Fonte:** `ecopontos/ecoforms`, pasta `volumosos-pwa/` (testes, documentação e regras ficam lá).
Esta pasta é só a cópia publicada — não edite aqui; atualize na fonte e copie os arquivos do app
(`index.html styles.css manifest.webmanifest icon.svg sw.js js/`), incrementando `VERSAO` em `sw.js`.
